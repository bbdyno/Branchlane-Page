시작하기

Branchlane은 Mac에 이미 있는 git을 씁니다. 처음 열 때 macOS가 명령어 라인 개발자 도구를 설치할지 물으면 설치하세요. 따로 만들 계정은 없습니다.

  1. 저장소 열기. 저장소 추가(⌘O)로 폴더를 고르거나, 저장소 복제(⇧⌘O)에 주소를 붙여 넣습니다.
  2. Git 신원 허락. App Sandbox 때문에 Branchlane은 허락 없이 홈 폴더를 읽지 못합니다. 설정 > Git 및 SSH에서 .gitconfig를 한 번 고르면 커밋에 내 이름과 이메일이 들어갑니다.
  3. 키 파일을 쓴다면 SSH 폴더 허락. ssh-agent에 올린 키는 그대로 동작합니다. 키 파일과 ~/.ssh/config까지 쓰려면 같은 곳에서 .ssh 폴더를 고릅니다.
  4. HTTPS 원격은 물어볼 때 로그인. 원격이 처음 인증을 요구할 때 사용자 이름과 토큰을 묻고, 기억하기를 고른 경우에만 키체인에 저장합니다.

매일 쓰는 Git

스테이징과 커밋

오른쪽 패널에 스테이징 안 된 파일과 스테이징된 파일이 나옵니다. 파일째 올리거나, 파일을 열어 헝크나 줄 단위로 올립니다. 줄은 바이트 그대로 인덱스에 쓰여서 CRLF 줄 끝이나 다른 인코딩 파일도 그대로 남습니다. 요약을 쓰고 커밋, 또는 커밋 후 푸시를 누릅니다.

브랜치

새 브랜치는 ⌘B, 브랜치 전환은 ⇧⌘B입니다. 그래프에서 브랜치를 다른 브랜치 위로 끌어 놓으면 병합하거나 리베이스하고, 오른쪽 클릭하면 모든 동작이 나옵니다. 가져오기 ⇧⌘F, 풀 ⇧⌘L, 푸시 ⇧⌘K.

병합 커밋 메시지

병합 커밋은 Merge branch 'develop' into feature처럼 브랜치 이름으로 남습니다. 설정 > Git 및 SSH > 병합에서 전체 ref(refs/heads/develop)나 커밋 해시로 바꿀 수 있습니다.

실행 취소

⌘Z로 체크아웃, 커밋, 리셋, 버리기, 브랜치 삭제, 스태시 삭제, 리베이스를 되돌리고 ⇧⌘Z로 다시 합니다. 기록이 Git 안에 남아서 앱을 껐다 켜도 됩니다.

스태시, 태그, 기록

스태시는 ⌥⌘S, 최근 스태시 꺼내기는 ⇧⌥⌘S입니다. 파일을 고르고 ⇧⌘H를 누르면 그 파일의 기록이 나오고, 차이 화면에서 blame을 열 수 있습니다.

Pro 도구

아래 기능은 Branchlane Pro가 필요합니다. 처음 구독하는 대상자는 14일 동안 무료로 써 볼 수 있습니다.

  • 인터랙티브 리베이스: 커밋을 오른쪽 클릭해 인터랙티브 리베이스를 고릅니다. 순서 바꾸기, 메시지 고치기, 스쿼시, 빼기를 정하고 시작합니다. 실행 취소 한 번이면 리베이스 전체가 돌아갑니다.
  • 충돌 편집기: 병합, 리베이스, 체리픽이 멈추면 충돌 파일을 열어 변경마다 내 쪽, 상대 쪽, 둘 다를 고릅니다. 충돌 경고는 병합 전에 부딪히는 곳을 알려 줍니다.
  • 워크트리, 비교, Git Flow, 패치는 왼쪽 패널과 오른쪽 클릭 메뉴에 있습니다.
  • PR과 이슈: 설정 > 통합에 GitHub나 GitLab 토큰을 넣습니다. 토큰은 키체인에 남고 호스트와 직접 통신합니다.
  • AI와 비서: 설정 > 비서에서 로컬 모델, 내 API 키, Apple 온디바이스 모델 중에서 고릅니다. 요청하기 전에는 아무것도 보내지 않습니다. 비서는 ⇧⌘I로 부르고, 비서가 제안한 변경은 내가 실행할 때까지 카드로 기다립니다.

에이전트 Lane

에이전트 Lane은 Claude Code, Codex 같은 코딩 에이전트에게 브랜치와 폴더를 따로 주고, 그 작업을 한 곳에서 검토하고 통합하게 합니다.

  1. 설정 > 에이전트에서 에이전트를 연결합니다. 에이전트마다 넣을 설정을 그대로 보여 주고, 서버는 이 Mac 안에서만 열립니다.
  2. 왼쪽 패널의 Lane 구역에서 Lane을 만들거나, 에이전트가 자기 도구로 시작하게 둡니다.
  3. 에이전트가 검토를 요청하면 Lane을 엽니다. 테스트 증거는 실행한 그 코드에만 유효하고, 위험한 파일이 먼저 나옵니다.
  4. 전부 받거나, 파일이나 헝크를 빼거나, 이유를 적어 돌려보냅니다. 통합한 Lane은 커밋 하나로 되돌릴 수 있습니다.

내 도구를 연결하려면 개발자 문서를 보세요.

문제 해결

훅이나 스크립트가 "operation not permitted"로 멈춤

macOS는 App Store 앱이 쓴 파일을 격리하고, 격리된 프로그램은 실행되지 않습니다. Branchlane에서 복제, 풀, 체크아웃으로 받은 훅과 스크립트는 터미널에서 아래 명령을 한 번 실행해야 합니다. Branchlane이 나중에 다시 쓴 파일도 마찬가지입니다.

xattr -dr com.apple.quarantine /path/to/repo

이 문제로 Git 작업이 막히면 Branchlane이 내 경로를 넣은 명령을 보여 줍니다. 원래 디스크에 있던 훅은 그대로 실행됩니다.

커밋에 작성자가 없음

설정 > Git 및 SSH에서 .gitconfig를 고르거나, 저장소에 이름과 이메일을 정합니다.

SSH가 호스트 키를 물어봄

호스트에 처음 연결할 때 지문이 나옵니다. 호스트가 공개한 지문과 같은지 확인하고 신뢰하세요. 신뢰한 호스트는 설정 > Git 및 SSH에 나옵니다.

저장소 밖 워크트리에 변경이 안 보임

샌드박스가 그 폴더에 접근하려면 허락이 필요합니다. 워크트리 줄에서 접근 허용을 한 번 고르면 다음에도 기억합니다.

앱 안에 터미널이 없음

Git 콘솔(⇧⌘C)은 Git 명령만 실행합니다. 그 밖의 일은 터미널에서 열기로 터미널에 넘깁니다.

도움 받기

질문이나 문제는 지원 페이지에 남겨 주세요. macOS 버전, Branchlane 메뉴에 나오는 Branchlane 버전, 기대한 동작을 적어 주시면 빠르게 볼 수 있습니다. 저장소 내용과 토큰은 넣지 마세요.
