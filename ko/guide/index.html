시작하기

이미 쓰던 Git, SSH 키, 원격으로 Branchlane을 설정합니다.

2026년 11월 25일 고침Branchlane 2.3

Branchlane은 Mac에 이미 있는 git을 씁니다. 처음 열 때 macOS가 명령어 라인 개발자 도구를 설치할지 물으면 설치하세요. 따로 만들 계정은 없습니다.

  1. 저장소 열기. 저장소 추가(⌘O)로 폴더를 고르거나, 저장소 복제(⇧⌘O)에 주소를 붙여 넣습니다.
  2. Git 신원 허락. App Sandbox 때문에 Branchlane은 허락 없이 홈 폴더를 읽지 못합니다. 설정 > Git 및 SSH에서 .gitconfig를 한 번 고르면 커밋에 내 이름과 이메일이 들어갑니다.
  3. 키 파일을 쓴다면 SSH 폴더 허락. ssh-agent에 올린 키는 그대로 동작합니다. 키 파일과 ~/.ssh/config까지 쓰려면 같은 곳에서 .ssh 폴더를 고릅니다.
  4. HTTPS 원격은 물어볼 때 로그인. 원격이 처음 인증을 요구할 때 사용자 이름과 토큰을 묻고, 기억하기를 고른 경우에만 키체인에 저장합니다.
