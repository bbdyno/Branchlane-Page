2026년 11월 25일 고침Branchlane 2.3

스테이징과 커밋#

오른쪽 패널에 스테이징 안 된 파일과 스테이징된 파일이 나옵니다. 파일째 올리거나, 파일을 열어 헝크나 줄 단위로 올립니다. 줄은 바이트 그대로 인덱스에 쓰여서 CRLF 줄 끝이나 다른 인코딩 파일도 그대로 남습니다. 요약을 쓰고 커밋, 또는 커밋 후 푸시를 누릅니다.

브랜치#

새 브랜치는 ⌘B, 브랜치 전환은 ⇧⌘B입니다. 그래프에서 브랜치를 다른 브랜치 위로 끌어 놓으면 병합하거나 리베이스하고, 오른쪽 클릭하면 모든 동작이 나옵니다. 가져오기 ⇧⌘F, 풀 ⇧⌘L, 푸시 ⇧⌘K.

병합 커밋 메시지#

병합 커밋은 Merge branch 'develop' into feature처럼 브랜치 이름으로 남습니다. 설정 > Git 및 SSH > 병합에서 전체 ref(refs/heads/develop)나 커밋 해시로 바꿀 수 있습니다.

실행 취소#

⌘Z로 체크아웃, 커밋, 리셋, 버리기, 브랜치 삭제, 스태시 삭제, 리베이스를 되돌리고 ⇧⌘Z로 다시 합니다. 기록이 Git 안에 남아서 앱을 껐다 켜도 됩니다.

스태시, 태그, 기록#

스태시는 ⌥⌘S, 최근 스태시 꺼내기는 ⇧⌥⌘S입니다. 파일을 고르고 ⇧⌘H를 누르면 그 파일의 기록이 나오고, 차이 화면에서 blame을 열 수 있습니다.
