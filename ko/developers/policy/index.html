정책 파일

저장소에서 에이전트가 해도 되는 일을 커밋한 파일 하나에 적습니다.

2026년 11월 25일 고침Branchlane 2.3

기본값#

메인 워크트리의 .branchlane/policy.json은 Branchlane과 연결된 에이전트에게 무엇이 허용되는지 알려 줍니다. 커밋해서 팀이 함께 쓰세요. 설정 > 에이전트에서 아래 기본값으로 만들 수 있습니다.

.branchlane/policy.json
{
  "forbid": ["force_push", "rewrite_history"],
  "protectedBranches": ["main", "master"],
  "protectedPaths": [],
  "requireApproval": ["push"],
  "requireEvidence": [],
  "sensitivePaths": []
}

판단하는 방법#

  • 동작은 push, force_push, rewrite_history, integrate입니다.
  • 판단 순서: 금지한 동작은 거절합니다. 보호 브랜치에서는 강제 푸시와 기록 다시 쓰기를 거절하고 나머지는 사람에게 묻습니다. 그 밖에는 requireApproval에 있는 동작만 사람에게 묻고 나머지는 허용합니다.
  • requireEvidence는 swift test 같은 명령 앞부분 목록입니다. 제안한 내용 그대로에서 통과한 증거가 있어야 Lane을 승인할 수 있습니다.
  • protectedPaths는 검토에서 파일마다 명시적으로 승인해야 합니다. sensitivePaths는 마이그레이션, 인증 코드, CI 워크플로, 잠금 파일, .env 같은 기본 목록에 더해 먼저 보여 줍니다.
  • 패턴은 .gitignore 규칙을 따르고 키는 camelCase입니다. 읽을 수 없는 파일은 기본값으로 돌아가고 오류는 설정에 나옵니다.

Claude Code#

설정 > 에이전트는 정책을 Claude Code permissions.deny 규칙으로도 바꿔 줍니다. Claude Code가 스스로 금지된 일을 거절하게 됩니다.
