체크포인트 훅

에이전트 턴이 끝날 때마다 체크포인트를 남깁니다.

2026년 11월 25일 고침Branchlane 2.3

POST /hook/checkpoint는 Claude Code가 보내는 훅 JSON에서 cwd를 읽습니다. 그 폴더가 Lane 워크트리 안이면 체크포인트를 남기고 {"checkpoint":true}를, 아니면 아무것도 하지 않고 false를 돌려줍니다. .claude/settings.local.json에 합칩니다.

.claude/settings.local.json
{
  "hooks": {
    "Stop": [{ "hooks": [{
      "type": "command",
      "command": "curl -s -m 5 -X POST -H 'Authorization: Bearer <token>' -H 'Content-Type: application/json' --data-binary @- http://127.0.0.1:47120/hook/checkpoint >/dev/null 2>&1 || true"
    }] }]
  }
}

Branchlane이 꺼져 있으면 조용히 실패해서 에이전트를 막지 않습니다.
