Branchlane 확장

내 모델 서버나 비서용 MCP 서버를 연결합니다.

2026년 11월 26일 고침Branchlane 2.3

내 모델 서버#

설정 > 비서는 OpenAI 호환 서버라면 무엇이든 받습니다. stream: true로 POST ../../../ko//chat/completions를 부르고 SSE나 일반 JSON 응답을 읽으며, 연결 확인에는 GET ../../../ko//models를 씁니다. 경로가 없으면 /v1을 붙이므로 Ollama(http://localhost:11434)와 LM Studio(http://localhost:1234)는 그대로 됩니다. 키는 다른 컴퓨터로 가는 일반 HTTP에는 절대 실리지 않습니다.

터미널
# Ollama: 모델을 받고 목록이 나오는지 확인
ollama pull llama3.2
curl -s http://localhost:11434/v1/models | jq -r '.data[].id'

# LM Studio: 서버를 켜고 같은 방법으로 확인
lms server start
curl -s http://localhost:1234/v1/models | jq -r '.data[].id'

목록이 나오면 그 주소를 설정 > 비서에 넣고 모델을 고릅니다.

저장소 데이터는 무작위 BEGIN data-…, END data-… 표시 사이에 넣고, 그 안은 지시가 아니라 데이터라고 모델에 알립니다.

비서용 내 MCP 서버#

사람이 설정 > 비서에 더한 MCP 서버의 도구를 비서가 부를 수 있습니다. Streamable HTTP(프로토콜 2025-06-18)를 HTTPS로, 또는 localhost에서는 HTTP로 열어 주세요. Branchlane은 MCP-Protocol-Version을 보내고 Mcp-Session-Id를 유지하며 Bearer 토큰을 붙일 수 있습니다. stdio 서버는 App Sandbox에서 띄울 수 없습니다.
