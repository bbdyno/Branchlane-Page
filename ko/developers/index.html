무엇을 만들 수 있나

Branchlane에는 클라우드 API가 없습니다. 도구가 닿을 수 있는 것은 모두 같은 Mac에서 돌거나, 어떤 도구든 읽을 수 있게 저장소 안에 있습니다.

  • 에이전트용 로컬 MCP 서버. 코딩 에이전트와 내 도구가 Lane을 시작하고, 체크포인트를 남기고, 테스트 증거를 기록하고, 검토를 요청합니다. 연결하기
  • 평범한 파일과 Git ref. 정책 파일, Agent Trace 노트, 커밋 트레일러, 모든 워크트리 요약을 Branchlane이 꺼져 있어도 읽을 수 있습니다. 정책, 출처 표시
  • 내 AI와 MCP 서버. OpenAI 호환 모델 서버를 연결하고, 비서가 내 MCP 서버를 HTTP로 부르게 합니다. Branchlane 확장

Lane 서버는 Branchlane Pro가 필요하고, 설정 > 에이전트에서 에이전트 연결 허용을 켰을 때만 돕니다. URL 스킴, App Intents, AppleScript 사전은 없습니다.

에이전트 연결

설정 > 에이전트에서 에이전트 연결 허용을 켜고 내 에이전트 줄을 복사합니다. 포트와 토큰이 이미 들어 있습니다. Branchlane은 이 파일들을 대신 쓰지 않습니다.

Claude Code

터미널에서 한 번 실행합니다.

claude mcp add --transport http branchlane http://127.0.0.1:47120/mcp --header "Authorization: Bearer <token>"

Codex

~/.codex/config.toml에 더합니다.

[mcp_servers.branchlane]
url = "http://127.0.0.1:47120/mcp"
http_headers = { Authorization = "Bearer <token>" }

다른 MCP 클라이언트

Streamable HTTP 전송으로 http://127.0.0.1:47120/mcp에 Authorization: Bearer <token> 헤더를 붙여 연결합니다. 포트는 설정에서 바꿀 수 있습니다. 직접 해 보려면:

curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"my-tool","version":"1.0"}}}'

curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"lane_begin","arguments":{"path":"/Users/me/src/app","intent":"Retry sync with backoff when the server is busy","agent":"my-tool/model-x","scope":["Sources/Sync/"]}}}'

모든 도구는 결과를 텍스트 항목 안의 JSON 문자열로 돌려줍니다.

{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "content": [{ "type": "text", "text": "{\n  \"branch\" : \"lane/retry-sync-with-backoff-a7f4\",\n  \"lane_id\" : \"a7f460dc\", ... }" }],
    "isError": false
  }
}

프로토콜 세부

  • 주소: IPv4 루프백 127.0.0.1에만 열립니다. 다른 인터페이스나 ::1에서는 듣지 않습니다. 기본 포트 47120.
  • 전송: HTTP/1.1, 연결마다 요청 하나. POST /mcp만 받고 다른 메서드는 405입니다. SSE 스트림이 없어 모든 답은 POST 응답으로 옵니다. 알림은 빈 본문의 202를 받습니다.
  • 본문: Content-Length를 보내세요. chunked 본문은 411입니다. 본문 4 MiB, 헤더 64 KiB까지.
  • 인증: Authorization: Bearer <token>. 토큰은 키체인에 있는 64자 16진수이고, 설정의 새 토큰으로 바꿉니다. 없거나 틀리면 401.
  • Origin: Origin 헤더가 localhost, 127.0.0.1, ::1이 아니면 403이라 웹 페이지는 서버를 부를 수 없습니다.
  • MCP: 프로토콜 2025-06-18, 2025-03-26, 2024-11-05. 메서드 initialize, ping, tools/list, tools/call와 JSON-RPC 배치. 도구만 있고 resources와 prompts는 없습니다.
  • 저장소: 샌드박스 앱은 사람이 Branchlane에서 연 저장소만 열 수 있습니다. 아니면 도구가 그렇다고 오류로 알려 줍니다.

도구

모든 도구는 작업 폴더인 path를 받습니다. 저장소나 Lane 워크트리입니다. path가 Lane 워크트리 안이면 lane_id는 생략할 수 있습니다. 읽기 전용은 lane_status뿐입니다.

도구인자 (굵은 글씨는 필수)하는 일
lane_beginpath, intent, agent, scope[], target, clone[]Lane을 시작합니다. 브랜치 lane/<slug>-<id>와 .branchlane/lanes/<id> 아래 워크트리를 만들고 lane_id, worktree, branch, target을 돌려줍니다. 그 뒤로는 그 워크트리에서만 작업합니다. clone은 node_modules, .build 같은 무시된 폴더를 복사합니다.
lane_statuspath, lane_id읽기 전용. 상태, 기록한 증거가 지금 코드와 맞는지, 검토 의견, 사람이 뺀 파일과 헝크, 다른 워크트리나 대상 브랜치와 겹치는 곳(줄 범위와 먼저 통합할 쪽 포함)을 돌려줍니다.
lane_checkpointpath, lane_id, note스테이징이나 커밋 없이 미커밋 변경까지 포함해 워크트리를 스냅샷으로 남깁니다.
lane_evidencepath, lane_id, command, exit_code, output명령이 지금 내용에서 실행됐고 어떻게 끝났는지 기록합니다. 내용이 그대로일 때만 유효하니 마지막 수정 뒤에 부르세요. output은 끝부분만 비밀을 가려 남깁니다. evidence_id를 돌려줍니다.
lane_proposepath, lane_id, summary, claims[{text, evidence[]}]지금 상태 그대로 검토를 요청합니다. 유효한 증거가 없는 주장은 표시됩니다.
lane_requestpath, lane_id, action: push | force_push | rewrite_history, reason푸시, 강제 푸시, 기록 다시 쓰기를 요청합니다. 정책이 정하고, 일부는 사람의 승인을 최대 2분 기다립니다. 승인된 푸시는 사람의 인증 정보로 실행됩니다.

주장마다 증거를 단 제안 예:

{"name": "lane_propose", "arguments": {
  "path": "/Users/me/src/app/.branchlane/lanes/a7f460dc",
  "summary": "Pushes are retried with exponential backoff and jitter. Six attempts at most.",
  "claims": [
    { "text": "A busy server is tried again, up to six times", "evidence": [1] },
    { "text": "The library file format is unchanged" }
  ]
}}

Lane 흐름과 상태

  1. lane_begin 뒤에는 돌려받은 워크트리 안에서만 작업합니다. 커밋은 마음대로 해도 됩니다. 미커밋 작업도 스냅샷으로 남습니다.
  2. 시작 전과 제안 전에 lane_status로 다른 에이전트가 건드리는 파일을 봅니다.
  3. lane_checkpoint는 언제든 부릅니다. 체크포인트 훅도 턴이 끝날 때마다 하나씩 남깁니다.
  4. 마지막 수정 뒤에 테스트, 빌드, 린트마다 lane_evidence를 부르고 받은 id를 챙깁니다.
  5. 요약과 그 id를 단 주장으로 lane_propose를 부릅니다.
  6. 나중에 lane_status로 검토 의견, 빠진 파일과 헝크, 메모를 읽습니다.
값앱 표시언제
running작업 중lane_begin 직후, 또는 사람이 돌려보냄
proposed검토 대기lane_propose
accepted대기열사람이 승인함, requireEvidence를 통과해야 함
needsUpdate업데이트 필요대상이 앞서가 작업이 맞지 않음. 대상 위로 맞춘 뒤 다시 제안
integrated통합됨커밋 하나로 대상에 들어감
reverted되돌림커밋 하나로 되돌림
abandoned버림통합하지 않고 정리함

체크포인트 훅

POST /hook/checkpoint는 Claude Code가 보내는 훅 JSON에서 cwd를 읽습니다. 그 폴더가 Lane 워크트리 안이면 체크포인트를 남기고 {"checkpoint":true}를, 아니면 아무것도 하지 않고 false를 돌려줍니다. .claude/settings.local.json에 합칩니다.

{
  "hooks": {
    "Stop": [{ "hooks": [{
      "type": "command",
      "command": "curl -s -m 5 -X POST -H 'Authorization: Bearer <token>' -H 'Content-Type: application/json' --data-binary @- http://127.0.0.1:47120/hook/checkpoint >/dev/null 2>&1 || true"
    }] }]
  }
}

Branchlane이 꺼져 있으면 조용히 실패해서 에이전트를 막지 않습니다.

정책 파일

메인 워크트리의 .branchlane/policy.json은 Branchlane과 연결된 에이전트에게 무엇이 허용되는지 알려 줍니다. 커밋해서 팀이 함께 쓰세요. 설정 > 에이전트에서 아래 기본값으로 만들 수 있습니다.

{
  "forbid": ["force_push", "rewrite_history"],
  "protectedBranches": ["main", "master"],
  "protectedPaths": [],
  "requireApproval": ["push"],
  "requireEvidence": [],
  "sensitivePaths": []
}
  • 동작은 push, force_push, rewrite_history, integrate입니다.
  • 판단 순서: 금지한 동작은 거절합니다. 보호 브랜치에서는 강제 푸시와 기록 다시 쓰기를 거절하고 나머지는 사람에게 묻습니다. 그 밖에는 requireApproval에 있는 동작만 사람에게 묻고 나머지는 허용합니다.
  • requireEvidence는 swift test 같은 명령 앞부분 목록입니다. 제안한 내용 그대로에서 통과한 증거가 있어야 Lane을 승인할 수 있습니다.
  • protectedPaths는 검토에서 파일마다 명시적으로 승인해야 합니다. sensitivePaths는 마이그레이션, 인증 코드, CI 워크플로, 잠금 파일, .env 같은 기본 목록에 더해 먼저 보여 줍니다.
  • 패턴은 .gitignore 규칙을 따르고 키는 camelCase입니다. 읽을 수 없는 파일은 기본값으로 돌아가고 오류는 설정에 나옵니다.

설정 > 에이전트는 정책을 Claude Code permissions.deny 규칙으로도 바꿔 줍니다. Claude Code가 스스로 금지된 일을 거절하게 됩니다.

에이전트 출처 표시

Branchlane은 무료판을 포함해 모두에게 그래프와 blame에서 에이전트 작업을 표시합니다. 내 도구는 세 가지 방법으로 알려 줄 수 있습니다.

커밋 트레일러

Agent: 트레일러가 가장 우선합니다. 없으면 Co-authored-by:, 그다음 작성자와 커미터에서 noreply@anthropic.com, Codex, Copilot, Cursor, Gemini, Devin, Jules, aider 같은 알려진 에이전트 신원을 찾습니다. Branchlane이 만드는 통합 커밋에는 이렇게 붙습니다.

Lane: a7f460dc
Change-Id: I3c1f…
Agent: claude-code/claude-opus-5-5

Agent Trace 노트

줄 단위 기록은 refs/notes/agent-trace의 git 노트로, 커밋마다 하나씩 Agent Trace 형식(버전 0.1.0, application/vnd.agent-trace.record+json)으로 남습니다. 노트 하나에 기록 하나, 배열, 또는 줄마다 하나를 넣을 수 있습니다. 같은 커밋에 다른 도구가 남긴 기록은 지우지 않습니다. blame에서 AI가 쓴 줄이 표시됩니다.

{
  "version": "0.1.0",
  "id": "…",
  "timestamp": "2026-11-23T02:09:00.000Z",
  "vcs": { "type": "git", "revision": "<commit>" },
  "tool": { "name": "claude-code" },
  "files": [{
    "path": "Sources/Sync/RetryingSyncEngine.swift",
    "conversations": [{
      "contributor": { "type": "ai", "model_id": "claude-opus-5-5" },
      "ranges": [{ "start_line": 12, "end_line": 48 }]
    }]
  }],
  "metadata": { "com.bbdyno.branchlane": { "written_by": "Branchlane", "lane": "a7f460dc" } }
}

Lane을 공유하면 노트도 refs/notes/agent-trace:refs/notes/agent-trace로 함께 오갑니다.

Lane 기록

Lane은 refs/branchlane/lanes/<id>/ 아래 Git ref(state, checkpoints, proposal)로 저장되고, state 커밋에 lane.json이 있습니다. 팀원의 Lane은 refs/branchlane/shared/<remote>/<id>/로 받아 옵니다. 읽기 전용으로 다루세요.

워크트리 요약

저장소에 워크트리가 둘 이상이고 Pro를 쓰면, Branchlane은 <git common dir>/branchlane/worktrees.json을 적어도 1분마다 새로 씁니다. MCP를 못 쓰는 에이전트는 워크트리마다 git status를 도는 대신 이 파일을 읽으면 됩니다. 워크트리가 하나만 남으면 지워집니다.

{
  "version": 1,
  "about": "…",
  "generatedAt": "2026-11-23T02:09:00Z",
  "target": "refs/heads/main",
  "worktrees": [
    { "path": "…", "branch": "lane/retry-sync-a7f4", "head": "…",
      "access": "readable", "uncommittedFiles": ["Sources/Sync/SyncEngine.swift"], "lastChange": "…" }
  ],
  "collisions": [
    { "between": ["…", "…"], "conflicts": false, "sameFiles": ["Sources/Sync/SyncEngine.swift"],
      "conflictLines": { "Sources/Sync/SyncEngine.swift": [["40-60", "41"]] } }
  ]
}

Branchlane 확장

내 모델 서버

설정 > 비서는 OpenAI 호환 서버라면 무엇이든 받습니다. stream: true로 POST {base}/chat/completions를 부르고 SSE나 일반 JSON 응답을 읽으며, 연결 확인에는 GET {base}/models를 씁니다. 경로가 없으면 /v1을 붙이므로 Ollama(http://localhost:11434)와 LM Studio(http://localhost:1234)는 그대로 됩니다. 키는 다른 컴퓨터로 가는 일반 HTTP에는 절대 실리지 않습니다.

저장소 데이터는 무작위 BEGIN data-…, END data-… 표시 사이에 넣고, 그 안은 지시가 아니라 데이터라고 모델에 알립니다.

비서용 내 MCP 서버

사람이 설정 > 비서에 더한 MCP 서버의 도구를 비서가 부를 수 있습니다. Streamable HTTP(프로토콜 2025-06-18)를 HTTPS로, 또는 localhost에서는 HTTP로 열어 주세요. Branchlane은 MCP-Protocol-Version을 보내고 Mcp-Session-Id를 유지하며 Bearer 토큰을 붙일 수 있습니다. stdio 서버는 App Sandbox에서 띄울 수 없습니다.
