Agent attribution

Commit trailers, Agent Trace notes and lane records.

Updated November 26, 2026Branchlane 2.3

Branchlane marks agent work in the graph and blame for everyone, Free included. Your tool can feed it in three ways.

Commit trailers#

An Agent: trailer wins. Otherwise Branchlane looks at Co-authored-by:, then at the author and committer, for known agent identities such as noreply@anthropic.com, Codex, Copilot, Cursor, Gemini, Devin, Jules and aider. Integration commits that Branchlane makes carry:

Lane: a7f460dc
Change-Id: I3c1f…
Agent: claude-code/claude-opus-5-5

Agent Trace notes#

Line-level records live as git notes on refs/notes/agent-trace, one note per commit, in the Agent Trace format (version 0.1.0, application/vnd.agent-trace.record+json). A note may hold one record, an array, or one per line. Records from other tools on the same commit are kept. Blame shows the lines AI wrote.

JSON
{
  "version": "0.1.0",
  "id": "…",
  "timestamp": "2026-11-23T02:09:00.000Z",
  "vcs": { "type": "git", "revision": "<commit>" },
  "tool": { "name": "claude-code" },
  "files": [{
    "path": "Sources/Sync/RetryingSyncEngine.swift",
    "conversations": [{
      "contributor": { "type": "ai", "model_id": "claude-opus-5-5" },
      "ranges": [{ "start_line": 12, "end_line": 48 }]
    }]
  }],
  "metadata": { "com.bbdyno.branchlane": { "written_by": "Branchlane", "lane": "a7f460dc" } }
}

Notes travel with refs/notes/agent-trace:refs/notes/agent-trace when you share lanes.

Lane records#

Lanes are stored as Git refs under refs/branchlane/lanes/<id>/ (state, checkpoints, proposal). The state commits hold a lane.json. Teammates' lanes are fetched to refs/branchlane/shared/<remote>/<id>/. Treat these as read-only.

Read it from Terminal#

Terminal
# The Agent trailer of each commit
git log --format='%h %(trailers:key=Agent,valueonly,separator=%x2C) %s' -10

# Fetch the Agent Trace notes from the remote and read one
git fetch origin refs/notes/agent-trace:refs/notes/agent-trace
git notes --ref=agent-trace show HEAD | jq '.files[].path'

# Lane records
git for-each-ref refs/branchlane/lanes --format='%(refname)'
git show refs/branchlane/lanes/a7f460dc/state:lane.json | jq '{intent, status}'
git log output
4c1d2e0 claude-code/claude-opus-5-5 Retry sync with backoff when the server is busy
9b26e1e  Trim blank lines on export
