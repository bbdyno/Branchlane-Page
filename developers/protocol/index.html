Protocol

Address, transport, limits, authentication and MCP versions.

Updated November 26, 2026Branchlane 2.3

Server#

  • AddressIPv4 loopback only, 127.0.0.1. Nothing listens on other interfaces or on ::1. Default port 47120.
  • TransportHTTP/1.1, one request per connection. Only POST /mcp is served; other methods get 405. There is no SSE stream, so every answer comes back on the POST. Notifications get 202 with an empty body.
  • BodySend Content-Length. Chunked bodies get 411. Bodies up to 4 MiB, headers up to 64 KiB.
  • AuthAuthorization: Bearer <token>, a 64-character hex token kept in the Keychain. New Token in Settings replaces it. Missing or wrong tokens get 401.
  • OriginA request with an Origin header that is not localhost, 127.0.0.1 or ::1 gets 403, so web pages cannot call the server.
  • MCPProtocol versions 2025-06-18, 2025-03-26 and 2024-11-05. Methods initialize, ping, tools/list and tools/call, and JSON-RPC batches. Tools only: no resources or prompts.
  • RepositoriesThe sandboxed app can only open repositories the person has opened in Branchlane. Otherwise the tool answers with an error that says so.

Status codes#

CodeWhen
200A result, also when a tool reports an error (isError)
202A notification, with an empty body
401A missing or wrong token
403An Origin that is not this Mac
405A method other than POST
411A chunked body, or no Content-Length

Try it#

Without a token you get a 401.

Terminal
curl -i -s -X POST http://127.0.0.1:47120/mcp -d '{}'
Output
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer
…

Unauthorized

Several requests can go in one JSON-RPC batch, and the answers come back as an array.

Terminal
curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[{"jsonrpc":"2.0","id":1,"method":"ping"},
       {"jsonrpc":"2.0","id":2,"method":"tools/list"}]' \
  | jq '.[].id'
