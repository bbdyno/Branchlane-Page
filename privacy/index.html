Branchlane Privacy Policy

Branchlane is designed as a private, native Git client for Mac. It does not require a Branchlane account, does not use a Branchlane-operated backend, and does not upload your repositories to a Branchlane server.

Last updated: November 10, 2026

Summary: Branchlane keeps repository data on your Mac. The app uses local Git, local preferences, macOS security-scoped bookmarks, StoreKit for App Store subscriptions, and direct connections from your Mac to services you choose, such as Git remotes, GitHub or GitLab, an AI provider you configured, MCP servers you connect, and Gravatar for profile pictures, which you can turn off.

1. Who We Are

Branchlane is a macOS Git client. This Privacy Policy explains how Branchlane handles information when you use the Branchlane app and related legal pages.

For privacy questions, contact us through the Branchlane support page at https://github.com/bbdyno/Branchlane-Page/issues.

2. Information Branchlane Does Not Collect

Branchlane does not operate a user account system, analytics backend, cloud sync service, repository hosting service, or custom license server. Branchlane does not collect, sell, rent, or share your repository contents through any Branchlane-operated server.

3. Information Stored Locally On Your Mac

Branchlane stores certain information locally so the app can work as expected. This may include:

  • Repository paths, recently opened repositories, selected tabs, and restore-on-launch state.
  • App preferences such as the theme, themes you made, date and time formatting, safety confirmations, and default clone folder.
  • Settings for AI providers, Git hosts and MCP servers, such as server addresses and model names. API keys and tokens are kept in macOS Keychain, not in these settings.
  • Profile pictures of commit authors, cached for up to a week in the app's cache folder.
  • The app's own known hosts file and Git config, kept in its App Sandbox container.
  • macOS security-scoped bookmarks that allow the app to reopen folders you selected.
  • Git metadata read from repositories, such as commit messages, branch names, tags, author names, author email addresses, file names, diffs, and working tree status.
  • Local subscription entitlement state provided by Apple's StoreKit APIs.

This information stays on your Mac unless you take an action that sends it elsewhere, such as pushing to a Git remote, cloning from a remote URL, fetching, pulling, invoking an AI action, or using GitHub or GitLab features directly from your Mac.

4. Repository Data And Git Operations

Branchlane runs Git operations locally through the Git executable on your Mac. When you interact with a Git remote, your Mac connects directly to that remote service using the remote URL and credentials configured for your repository or system. Examples include GitHub, GitLab, Bitbucket, a self-hosted Git server, or another Git remote you choose.

Branchlane does not proxy these Git operations through a Branchlane server.

5. App Store Subscriptions

Branchlane Pro subscriptions are handled through Apple's StoreKit and the App Store. Apple processes purchases, renewals, cancellations, refunds, payment information, and subscription management. Branchlane does not receive your full payment card details.

Branchlane uses StoreKit to load available subscription products, start purchases, restore purchases, and check whether an active entitlement exists on your Mac.

6. Optional AI

AI features are optional. Repository content, such as diffs and commit data, is sent only when you invoke an AI action, and only to the provider you configured: a local server, Anthropic, OpenAI or a compatible service, or Apple's on-device model.

Requests go directly from your Mac to that provider, and Apple's on-device model runs on your Mac. No Branchlane server is involved. Before the first send to a non-local provider, Branchlane asks you to confirm. A provider that receives your content handles it under its own terms and policies.

API keys stay in macOS Keychain.

The assistant, part of Branchlane Pro, uses the same provider. When you send it a message, it sends your message, a short description of what is selected in the app, and what it reads from the open repository, such as status, history, diffs and file contents, to that provider so it can answer. It reads only the open repository. Anything that would change the repository waits until you run it. Conversations are kept in memory and are not saved when you quit.

MCP servers are optional and connected by you, over HTTP. When the assistant uses a tool from one of them, the tool's arguments, which the model writes and may include repository details, go directly from your Mac to that server. Tools that the server does not mark as read-only ask you first. Tokens for MCP servers stay in macOS Keychain.

7. GitHub, GitLab And Profile Pictures

Pull request and issue features connect to GitHub or GitLab only if you add a token. Requests go directly from your Mac to that host, using your own token stored in macOS Keychain. No Branchlane server is involved. The host receives those requests according to its own policies.

To show commit authors' profile pictures, Branchlane asks the repository's GitHub or GitLab host which account a commit's author email belongs to, when you added a token for that host, and otherwise asks Gravatar. Gravatar receives only a SHA-256 hash of the email address, never the address itself. GitHub no-reply addresses name their account, so their pictures load from GitHub directly. You can turn profile pictures off in Settings > General.

8. Third-Party Services

Git remotes

When you clone, fetch, pull, push, or publish branches, your Mac connects directly to the Git remote configured for that repository. The remote service may receive repository data, credentials, network information, and Git metadata according to that service's own policies.

Gravatar

When profile pictures are on, Gravatar receives hashed email addresses of commit authors and your network information, according to its own policies.

MCP servers

MCP servers you connect receive the tool calls the assistant makes, according to the policies of whoever runs them.

Apple

Apple may process purchase, subscription, diagnostic, crash, and App Store analytics information according to Apple's own policies and the settings you have chosen for your Apple ID, device, and App Store account.

9. Credentials And Local Git Files

Branchlane relies on Git and macOS mechanisms for repository authentication. HTTPS tokens, GitHub and GitLab tokens, and AI API keys are stored in macOS Keychain. Branchlane does not operate a Branchlane credential server.

Branchlane runs in the App Sandbox and keeps its own known hosts file and Git config in its container. It can access your ~/.gitconfig and ~/.ssh only if you explicitly grant access in the app.

10. Data Retention And Deletion

Local app data remains on your Mac until you remove it, reset app preferences, remove repository entries, or uninstall the app and delete its local container data. Repository data remains wherever you store your repositories and wherever you send it through Git operations.

11. Children

Branchlane is a developer tool and is not directed to children. Branchlane does not knowingly collect personal information from children through a Branchlane-operated service.

12. Changes To This Policy

We may update this Privacy Policy as Branchlane changes. The updated version will be posted on this page with a new "Last updated" date.

13. Contact

For questions about this Privacy Policy, contact us through the Branchlane support page.
