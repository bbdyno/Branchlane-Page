When a repository has more than one worktree and the person has Pro, Branchlane keeps <git common dir>/branchlane/worktrees.json up to date, at least once a minute. Agents that do not speak MCP can read it instead of running git status in every worktree. It is removed when only one worktree is left.

{
  "version": 1,
  "about": "…",
  "generatedAt": "2026-11-23T02:09:00Z",
  "target": "refs/heads/main",
  "worktrees": [
    { "path": "…", "branch": "lane/retry-sync-a7f4", "head": "…",
      "access": "readable", "uncommittedFiles": ["Sources/Sync/SyncEngine.swift"], "lastChange": "…" }
  ],
  "collisions": [
    { "between": ["…", "…"], "conflicts": false, "sameFiles": ["Sources/Sync/SyncEngine.swift"],
      "conflictLines": { "Sources/Sync/SyncEngine.swift": [["40-60", "41"]] } }
  ]
}

Read it

The file sits in Git's common directory, so the same path works from any worktree.

f="$(git rev-parse --git-common-dir)/branchlane/worktrees.json"

# Uncommitted files in each worktree
jq -r '.worktrees[] | "\(.branch)\t\(.uncommittedFiles | length)"' "$f"

# Only the pairs that will really conflict
jq '.collisions[] | select(.conflicts)' "$f"
