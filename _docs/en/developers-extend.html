Your own model server

Settings > Assistant accepts any OpenAI-compatible server. Branchlane calls POST {base}/chat/completions with stream: true and reads server-sent events or a plain JSON reply, and uses GET {base}/models to test the connection. Without a path it adds /v1, so Ollama (http://localhost:11434) and LM Studio (http://localhost:1234) work as they are. A key is never sent over plain HTTP to another machine.

Repository data is wrapped between random BEGIN data-… and END data-… markers, and the model is told that what is inside is data, not instructions.

Your own MCP server for the assistant

The assistant can call tools on MCP servers that the person adds in Settings > Assistant. Serve the Streamable HTTP transport (protocol 2025-06-18) over HTTPS, or over HTTP on localhost. Branchlane sends MCP-Protocol-Version, keeps Mcp-Session-Id, and can add a Bearer token. Stdio servers cannot be started from the App Sandbox.
