What you can build

Branchlane has no cloud API. Everything a tool can reach runs on the same Mac, or lives in the repository where any tool can read it.

  • A local MCP server for agents. Coding agents and your own tools start lanes, save checkpoints, record test evidence and ask for review. Connect
  • The agent kit. A public repository with a Claude Code plugin, Codex settings and a shared mcp.json. GitHub, install
  • Plain files and Git refs. A policy file, Agent Trace notes, commit trailers and a summary of every worktree, all readable without Branchlane running. Policy, attribution
  • Your own AI and MCP servers. Point Branchlane at any OpenAI-compatible model server, and let its assistant call your MCP server over HTTP. Extend Branchlane

Check it in a minute

Turn on connections in Settings > Agents, copy the token, and see whether the server answers.

export BRANCHLANE_TOKEN="the token from Settings"

curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  | jq -r '.result.tools[].name'

Before you start

The lane server needs Branchlane Pro and runs only while Let agents connect is on in Settings > Agents. Branchlane has no URL scheme, App Intents or AppleScript dictionary.
