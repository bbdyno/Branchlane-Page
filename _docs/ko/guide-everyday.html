스테이징과 커밋

오른쪽 패널에 스테이징 안 된 파일과 스테이징된 파일이 나옵니다. 파일째 올리거나, 파일을 열어 헝크나 줄 단위로 올립니다. 요약을 쓰고 커밋, 또는 커밋 후 푸시를 누릅니다.

파일 목록과 커밋 입력. 수정 커밋을 켜면 마지막 커밋을 고칩니다

줄 단위로 올리기

차이 화면에서 줄을 고르면 아래에 줄 스테이징과 줄 폐기가 나옵니다. 헝크 하나에서 일부 줄만 커밋하거나 버릴 때 씁니다. 줄은 바이트 그대로 인덱스에 쓰여서 CRLF 줄 끝이나 다른 인코딩 파일도 그대로 남습니다.

새 함수의 다섯 줄만 골라 스테이징

브랜치

새 브랜치는 ⌘B, 브랜치 전환은 ⇧⌘B입니다. 그래프에서 브랜치를 다른 브랜치 위로 끌어 놓으면 병합하거나 리베이스하고, 오른쪽 클릭하면 모든 동작이 나옵니다. 가져오기 ⇧⌘F, 풀 ⇧⌘L, 푸시 ⇧⌘K.

병합된 브랜치 정리

로컬 섹션 메뉴나 명령 팔레트에서 병합된 브랜치 정리를 고릅니다. 병합, 리베이스, 스쿼시로 이미 기본 브랜치에 들어간 브랜치와, 풀 리퀘스트가 병합되며 원격에서 지워진 브랜치를 보여 줍니다. 체크아웃한 브랜치, 다른 워크트리에서 열린 브랜치, Lane 브랜치, main·develop 같은 오래 가는 브랜치는 빠집니다. 지울 것을 고르면 되고, 실행 취소로 되돌릴 수 있습니다.

워크트리

워크트리 섹션에서, 또는 브랜치를 오른쪽 클릭해 워크트리 만들기를 고르면 다른 브랜치를 별도 폴더에 엽니다. 워크트리마다 탭이 하나씩 열립니다.

병합 커밋 메시지

병합 커밋은 Merge branch 'develop' into feature처럼 브랜치 이름으로 남습니다. 설정 > Git 및 SSH > 병합에서 전체 ref(refs/heads/develop)나 커밋 해시로 바꿀 수 있습니다.

실행 취소

⌘Z로 체크아웃, 커밋, 리셋, 버리기, 브랜치 삭제, 스태시 삭제, 리베이스를 되돌리고 ⇧⌘Z로 다시 합니다. 기록이 Git 안에 남아서 앱을 껐다 켜도 됩니다.

스태시, 태그, 기록

스태시는 ⌥⌘S, 최근 스태시 꺼내기는 ⇧⌥⌘S입니다. 파일을 고르고 ⇧⌘H를 누르면 그 파일의 기록이 나오고, 차이 화면에서 blame을 열 수 있습니다.

안전

폴더의 Git 설정이나 훅이 프로그램을 실행하거나 접속 경로를 바꾸면, Branchlane은 그 목록을 보여 주고 허락할 때까지 저장소를 쓰지 않으며, 바뀌면 다시 묻습니다. 커밋과 푸시 전에는 키, 토큰, 비밀번호를 찾아 그 줄을 보여 줍니다. 설정 > Git 및 SSH에서 ssh-agent의 키로 커밋과 태그에 서명할 수 있고, 커밋마다 서명 상태가 보입니다.

Git 명령으로 보면

터미널에 익숙하다면 아래처럼 대응합니다. Git 콘솔(⇧⌘C)에서 Git 명령을 직접 실행할 수도 있습니다.

Branchlane에서비슷한 Git 명령
파일 스테이징git add <파일>
헝크나 줄 스테이징git add -p <파일>
모두 스테이징 해제git restore --staged .
수정 커밋git commit --amend
커밋 후 푸시git commit -m "…" && git push
새 브랜치 ⌘Bgit switch -c <이름>
스태시 / 꺼내기git stash push / git stash pop
파일 기록 ⇧⌘Hgit log --follow -- <파일>
