공통 인자

모든 도구가 받습니다.

인자형식설명
path필수string작업 폴더. 저장소나 Lane 워크트리입니다.
lane_idstringpath가 Lane 워크트리 안이면 생략할 수 있습니다.

lane_begin

Lane을 시작합니다. 브랜치 lane/<slug>-<id>와 .branchlane/lanes/<id> 아래 워크트리를 만듭니다. 그 뒤로는 그 워크트리에서만 작업합니다. lane_id, worktree, branch, target을 돌려줍니다.

인자형식설명
intent필수string사람이 부탁한 일을 한두 문장으로 적습니다.
agentstring도구와 모델. 예: claude-code/claude-opus-5-5
scopestring[]바꿀 것 같은 경로. 충돌 경고의 실마리로 씁니다.
targetstring작업이 들어갈 브랜치. 생략하면 저장소의 메인 브랜치입니다.
clonestring[]메인 워크트리에서 복사할 무시된 폴더. 예: node_modules, .build

lane_status읽기 전용

Lane의 상태, 기록한 증거가 지금 코드와 맞는지, 검토 의견, 사람이 뺀 파일과 헝크, 다른 워크트리나 대상 브랜치와 겹치는 곳(줄 범위와 먼저 통합할 쪽 포함)을 돌려줍니다.

lane_checkpoint

스테이징이나 커밋 없이 미커밋 변경까지 포함해 워크트리를 스냅샷으로 남깁니다.

인자형식설명
notestring스냅샷에 남길 메모.

lane_evidence

명령이 지금 내용에서 실행됐고 어떻게 끝났는지 기록합니다. 내용이 그대로일 때만 유효하니 마지막 수정 뒤에 부르세요. evidence_id를 돌려줍니다.

인자형식설명
command필수string실행한 명령. 예: swift test
exit_code필수integer끝난 값. 0이면 통과입니다.
outputstring명령의 출력. 끝부분만 비밀을 가려 남깁니다.

lane_propose

지금 상태 그대로 검토를 요청합니다. 유효한 증거가 없는 주장은 표시됩니다.

인자형식설명
summary필수string검토하는 사람에게 보여 줄, 바꾼 내용과 이유.
claimsobject[]주장과 그것을 받치는 증거 id. { text, evidence[] }

예시

{"name": "lane_propose", "arguments": {
  "path": "/Users/me/src/app/.branchlane/lanes/a7f460dc",
  "summary": "Pushes are retried with exponential backoff and jitter. Six attempts at most.",
  "claims": [
    { "text": "A busy server is tried again, up to six times", "evidence": [1] },
    { "text": "The library file format is unchanged" }
  ]
}}

lane_request

푸시, 강제 푸시, 기록 다시 쓰기를 요청합니다. 정책이 정하고, 일부는 사람의 승인을 최대 2분 기다립니다. 승인된 푸시는 사람의 인증 정보로 실행됩니다.

인자형식설명
action필수enumpush, force_push, rewrite_history 중 하나.
reasonstring사람에게 보여 줄 이유.
