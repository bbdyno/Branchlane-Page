여기서 시작

에이전트 연결Claude Code, Codex, 다른 MCP 클라이언트를 한 줄로 연결합니다. Lane 흐름시작부터 검토까지 부르는 순서입니다. 도구도구마다의 인자와 결과입니다. 정책 파일저장소에서 에이전트가 해도 되는 일입니다.

무엇을 만들 수 있나

Branchlane에는 클라우드 API가 없습니다. 도구가 닿을 수 있는 것은 모두 같은 Mac에서 돌거나, 어떤 도구든 읽을 수 있게 저장소 안에 있습니다.

  • 에이전트용 로컬 MCP 서버. 코딩 에이전트와 내 도구가 Lane을 시작하고, 체크포인트를 남기고, 테스트 증거를 기록하고, 검토를 요청합니다. 연결하기
  • 평범한 파일과 Git ref. 정책 파일, Agent Trace 노트, 커밋 트레일러, 모든 워크트리 요약을 Branchlane이 꺼져 있어도 읽을 수 있습니다. 정책, 출처 표시
  • 내 AI와 MCP 서버. OpenAI 호환 모델 서버를 연결하고, 비서가 내 MCP 서버를 HTTP로 부르게 합니다. Branchlane 확장

시작하기 전에

Lane 서버는 Branchlane Pro가 필요하고, 설정 > 에이전트에서 에이전트 연결 허용을 켰을 때만 돕니다. URL 스킴, App Intents, AppleScript 사전은 없습니다.
