Branchlane은 무료판을 포함해 모두에게 그래프와 blame에서 에이전트 작업을 표시합니다. 내 도구는 세 가지 방법으로 알려 줄 수 있습니다.

커밋 트레일러

Agent: 트레일러가 가장 우선합니다. 없으면 Co-authored-by:, 그다음 작성자와 커미터에서 noreply@anthropic.com, Codex, Copilot, Cursor, Gemini, Devin, Jules, aider 같은 알려진 에이전트 신원을 찾습니다. Branchlane이 만드는 통합 커밋에는 이렇게 붙습니다.

Lane: a7f460dc
Change-Id: I3c1f…
Agent: claude-code/claude-opus-5-5

Agent Trace 노트

줄 단위 기록은 refs/notes/agent-trace의 git 노트로, 커밋마다 하나씩 Agent Trace 형식(버전 0.1.0, application/vnd.agent-trace.record+json)으로 남습니다. 노트 하나에 기록 하나, 배열, 또는 줄마다 하나를 넣을 수 있습니다. 같은 커밋에 다른 도구가 남긴 기록은 지우지 않습니다. blame에서 AI가 쓴 줄이 표시됩니다.

{
  "version": "0.1.0",
  "id": "…",
  "timestamp": "2026-11-23T02:09:00.000Z",
  "vcs": { "type": "git", "revision": "<commit>" },
  "tool": { "name": "claude-code" },
  "files": [{
    "path": "Sources/Sync/RetryingSyncEngine.swift",
    "conversations": [{
      "contributor": { "type": "ai", "model_id": "claude-opus-5-5" },
      "ranges": [{ "start_line": 12, "end_line": 48 }]
    }]
  }],
  "metadata": { "com.bbdyno.branchlane": { "written_by": "Branchlane", "lane": "a7f460dc" } }
}

Lane을 공유하면 노트도 refs/notes/agent-trace:refs/notes/agent-trace로 함께 오갑니다.

Lane 기록

Lane은 refs/branchlane/lanes/<id>/ 아래 Git ref(state, checkpoints, proposal)로 저장되고, state 커밋에 lane.json이 있습니다. 팀원의 Lane은 refs/branchlane/shared/<remote>/<id>/로 받아 옵니다. 읽기 전용으로 다루세요.
