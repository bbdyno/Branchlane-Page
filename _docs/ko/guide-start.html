Branchlane은 Mac에 이미 있는 git을 씁니다. 처음 열 때 macOS가 명령어 라인 개발자 도구를 설치할지 물으면 설치하세요. 따로 만들 계정은 없습니다.

  1. 도구 막대. 실행 취소, 가져오기, 풀, 푸시, 브랜치, 스태시가 있습니다. 푸시 버튼의 숫자는 아직 보내지 않은 커밋 수입니다.
  2. 왼쪽 패널. 로컬과 원격 브랜치, PR, 스태시, 태그, Git Flow입니다. ⌘J로 접습니다.
  3. 커밋 그래프. 브랜치마다 줄이 곧게 이어집니다. 맨 위 // WIP 줄은 아직 커밋하지 않은 변경입니다.
  4. 오른쪽 패널. 변경 사항, 커밋 입력, 비서입니다. 그래프에서 커밋을 누르면 그 커밋의 내용이 나옵니다. ⌘K로 접습니다.

처음 설정

  1. 저장소 열기. 저장소 추가(⌘O)로 폴더를 고르거나, 저장소 복제(⇧⌘O)에 주소를 붙여 넣습니다.
  2. Git 신원 허락. App Sandbox 때문에 Branchlane은 허락 없이 홈 폴더를 읽지 못합니다. 설정 > Git 및 SSH에서 .gitconfig를 한 번 고르면 커밋에 내 이름과 이메일이 들어갑니다.
  3. 키 파일을 쓴다면 SSH 폴더 허락. ssh-agent에 올린 키는 그대로 동작합니다. 키 파일과 ~/.ssh/config까지 쓰려면 같은 곳에서 .ssh 폴더를 고릅니다.
  4. HTTPS 원격은 물어볼 때 로그인. 원격이 처음 인증을 요구할 때 사용자 이름과 토큰을 묻고, 기억하기를 고른 경우에만 키체인에 저장합니다.

터미널에서 미리 확인하기

앱이 쓰는 것과 같은 Git과 SSH 설정입니다. 이미 되어 있으면 건너뛰세요.

# 명령어 라인 개발자 도구와 Git
xcode-select --install
git --version

# 커밋에 들어갈 이름과 이메일
git config --global user.name "Kim Minji"
git config --global user.email "minji@example.com"

# 키를 ssh-agent에 올리고 GitHub 연결 확인
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
ssh -T git@github.com

마지막 명령이 You've successfully authenticated로 끝나면 Branchlane에서도 SSH 원격을 그대로 쓸 수 있습니다.
