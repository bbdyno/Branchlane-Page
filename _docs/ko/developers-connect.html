서버 더하기

설정 > 에이전트에서 에이전트 연결 허용을 켜고 내 에이전트 줄을 복사합니다. 포트와 토큰이 이미 들어 있습니다. Branchlane은 이 파일들을 대신 쓰지 않습니다.

터미널에서 한 번 실행하고, 연결됐는지 확인합니다.

claude mcp add --transport http branchlane \
  http://127.0.0.1:47120/mcp \
  --header "Authorization: Bearer <token>"

claude mcp list

~/.codex/config.toml에 더합니다.

[mcp_servers.branchlane]
url = "http://127.0.0.1:47120/mcp"
http_headers = { Authorization = "Bearer <token>" }

Streamable HTTP 전송으로 http://127.0.0.1:47120/mcp에 Authorization: Bearer <token> 헤더를 붙여 연결합니다. 포트는 설정에서 바꿀 수 있습니다.

{
  "mcpServers": {
    "branchlane": {
      "type": "http",
      "url": "http://127.0.0.1:47120/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}

설정 파일 모양은 클라이언트마다 조금씩 다릅니다. 주소와 헤더만 맞으면 됩니다.

연결 키트로 한 번에

Branchlane Agent Kit은 위 설정에 에이전트가 Lane을 쓰는 방법까지 묶은 공개 저장소입니다. Claude Code에는 MCP 서버, 스킬 두 개, 턴이 끝날 때마다 체크포인트를 남기는 훅이 함께 들어갑니다. 토큰은 파일에 적지 않고 환경 변수로 읽습니다.

export BRANCHLANE_TOKEN="설정에서 복사한 토큰"

claude plugin marketplace add bbdyno/branchlane-agent-kit
claude plugin install branchlane@branchlane

플러그인을 쓰면 위의 claude mcp add 줄은 실행하지 않습니다.

키트의 codex/config.toml을 ~/.codex/config.toml에, codex/AGENTS.snippet.md를 저장소의 AGENTS.md에 더합니다.

키트의 clients/mcp.json을 씁니다. 환경 변수를 펼치지 않는 클라이언트는 주소와 헤더를 직접 넣습니다.

App Store 판은 2.3입니다. 키트의 충돌 도구 세 개는 2.4부터 동작하고, 그 밖의 기능은 2.3에서 됩니다.

직접 불러 보기

토큰을 환경 변수에 넣고 세션을 시작합니다.

export BRANCHLANE_TOKEN="설정에서 복사한 토큰"

curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "jsonrpc": "2.0", "id": 1, "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {},
    "clientInfo": { "name": "my-tool", "version": "1.0" }
  }
}'
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "protocolVersion": "2025-06-18",
    "capabilities": { "tools": { "listChanged": false } },
    "serverInfo": { "name": "branchlane", "version": "1" },
    "instructions": "Branchlane coordinates parallel agents in this repository. Start each task with lane_begin and work in the worktree it returns. …"
  }
}

도구를 부릅니다. path는 Branchlane에서 연 저장소여야 합니다.

curl -s http://127.0.0.1:47120/mcp \
  -H "Authorization: Bearer $BRANCHLANE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "jsonrpc": "2.0", "id": 2, "method": "tools/call",
  "params": {
    "name": "lane_begin",
    "arguments": {
      "path": "/Users/me/src/app",
      "intent": "Retry sync with backoff when the server is busy",
      "agent": "my-tool/model-x",
      "scope": ["Sources/Sync/"]
    }
  }
}'

결과 읽기

모든 도구는 결과를 텍스트 항목 안의 JSON 문자열로 돌려줍니다.

{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "content": [{ "type": "text", "text": "{\n  \"branch\" : \"lane/retry-sync-with-backoff-a7f4\",\n  \"cloned\" : [],\n  \"lane_id\" : \"a7f460dc\", ... }" }],
    "isError": false
  }
}

jq로 안쪽 JSON을 풀면 이렇게 보입니다.

curl -s … | jq '.result.content[0].text | fromjson'
{
  "branch": "lane/retry-sync-with-backoff-a7f4",
  "cloned": [],
  "lane_id": "a7f460dc",
  "next": "Work only inside `worktree`. Commit there as you like; Branchlane snapshots uncommitted work too.",
  "target": "refs/heads/main",
  "worktree": "/Users/me/src/app/.branchlane/lanes/a7f460dc"
}

도구가 실패하면 HTTP는 그대로 200이고 isError가 true이며, 텍스트에 이유가 들어 있습니다.
