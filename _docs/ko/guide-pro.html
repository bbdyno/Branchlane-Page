인터랙티브 리베이스

커밋을 오른쪽 클릭해 인터랙티브 리베이스를 고릅니다. 순서 바꾸기, 메시지 고치기, 스쿼시, 빼기를 정하고 리베이스 시작을 누릅니다. 실행 취소 한 번이면 리베이스 전체가 돌아갑니다.

커밋 12개를 8개로 합치는 계획. 위쪽에 결과가, 아래쪽에 키 안내가 나옵니다

목록에서는 키로 고르는 편이 빠릅니다. P 선택, R 메시지 수정, S 스쿼시, D 삭제, ⌥↑ ⌥↓로 커밋을 옮깁니다.

쌓은 브랜치

브랜치를 오른쪽 클릭해 그 위에 새 브랜치 쌓기를 고릅니다. 새 브랜치에서 평소처럼 일합니다. 아래 브랜치를 고치거나 리베이스했다면 그 브랜치를 오른쪽 클릭해 다시 쌓기를 고릅니다. 위에 쌓인 브랜치마다 자기 커밋만 부모 위로 옮겨집니다. 단계마다 평범한 리베이스라 실행 취소로 되돌립니다. 중간에 충돌로 멈추면 충돌을 풀고 리베이스를 마친 뒤 다시 쌓기를 한 번 더 고르면 됩니다. 이미 맞춰진 브랜치는 건너뜁니다. 스택에서 빼기로 브랜치를 스택 밖으로 꺼냅니다.

충돌 편집기

병합, 리베이스, 체리픽이 멈추면 충돌 파일을 엽니다. 위에 두 쪽이 나란히, 아래에 결과가 나옵니다. 충돌 경고는 병합 전에 부딪힐 곳을 미리 알려 줍니다.

  1. 내 쪽. 지금 체크아웃한 브랜치입니다.
  2. 상대 쪽. 병합되는 브랜치입니다.
  3. 결과. 아직 고르지 않은 충돌은 빨간 칸으로 남고, 자동으로 병합된 곳은 따로 표시됩니다.
  4. 충돌마다 고르기. 내 변경, 상대 변경, 둘 다, 둘 다 역순, 베이스 중에서 고르거나 직접 편집합니다. 다 고르면 위쪽 막대의 계속을 누릅니다.

AI와 비서

설정 > 비서에서 로컬 모델, 내 API 키, Apple 온디바이스 모델 중에서 고릅니다. 요청하기 전에는 아무것도 보내지 않습니다. 비서는 ⇧⌘I로 부르고, 비서가 제안한 변경은 내가 실행을 누를 때까지 카드로 기다립니다.

읽은 것은 위에 펼쳐 볼 수 있고, 바꾸는 일은 카드로 기다립니다

이 Mac에서 모델을 돌리려면 Ollama로 모델을 받고, 설정 > 비서에 http://localhost:11434를 넣습니다.

ollama pull llama3.2
curl -s http://localhost:11434/v1/models

그 밖의 Pro 도구

  • 비교, Git Flow, 패치는 왼쪽 패널과 오른쪽 클릭 메뉴에 있습니다.
  • PR과 이슈: 설정 > 통합에 GitHub, GitLab, Bitbucket 토큰을 넣습니다. Bitbucket Cloud는 Atlassian에서 범위를 지정하는 API 토큰을 만들고, 앱으로 Bitbucket을 골라 read:user:bitbucket, read:repository:bitbucket, read:pullrequest:bitbucket, write:pullrequest:bitbucket을 켠 뒤 email:token 형식으로 넣습니다. 저장소나 워크스페이스 액세스 토큰은 그대로 넣습니다. Bitbucket Cloud는 이슈 기능을 없애서 풀 리퀘스트만 쓸 수 있습니다. 토큰은 키체인에 남고 호스트와 직접 통신합니다.
  • 테마: White와 Black 밖의 테마는 Pro입니다. 무료판에서도 설정 > 테마에서 미리 볼 수 있습니다.
