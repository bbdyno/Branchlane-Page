훅이나 스크립트가 "operation not permitted"로 멈춤

macOS는 App Store 앱이 쓴 파일을 격리하고, 격리된 프로그램은 실행되지 않습니다. Branchlane에서 복제, 풀, 체크아웃으로 받은 훅과 스크립트는 터미널에서 아래 명령을 한 번 실행해야 합니다. Branchlane이 나중에 다시 쓴 파일도 마찬가지입니다.

xattr -dr com.apple.quarantine /path/to/repo

이 문제로 Git 작업이 막히면 Branchlane이 내 경로를 넣은 명령을 보여 줍니다. 원래 디스크에 있던 훅은 그대로 실행됩니다.

커밋에 작성자가 없음

설정 > Git 및 SSH에서 .gitconfig를 고르거나, 저장소에 이름과 이메일을 정합니다.

SSH가 호스트 키를 물어봄

호스트에 처음 연결할 때 지문이 나옵니다. 호스트가 공개한 지문과 같은지 확인하고 신뢰하세요. 신뢰한 호스트는 설정 > Git 및 SSH에 나옵니다.

저장소 밖 워크트리에 변경이 안 보임

샌드박스가 그 폴더에 접근하려면 허락이 필요합니다. 워크트리 줄에서 접근 허용을 한 번 고르면 다음에도 기억합니다.

앱 안에 터미널이 없음

Git 콘솔(⇧⌘C)은 Git 명령만 실행합니다. 그 밖의 일은 터미널에서 열기로 터미널에 넘깁니다.
