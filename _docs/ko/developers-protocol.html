서버

  • 주소IPv4 루프백 127.0.0.1에만 열립니다. 다른 인터페이스나 ::1에서는 듣지 않습니다. 기본 포트 47120.
  • 전송HTTP/1.1, 연결마다 요청 하나. POST /mcp만 받고 다른 메서드는 405입니다. SSE 스트림이 없어 모든 답은 POST 응답으로 옵니다. 알림은 빈 본문의 202를 받습니다.
  • 본문Content-Length를 보내세요. chunked 본문은 411입니다. 본문 4 MiB, 헤더 64 KiB까지.
  • 인증Authorization: Bearer <token>. 토큰은 키체인에 있는 64자 16진수이고, 설정의 새 토큰으로 바꿉니다. 없거나 틀리면 401.
  • OriginOrigin 헤더가 localhost, 127.0.0.1, ::1이 아니면 403이라 웹 페이지는 서버를 부를 수 없습니다.
  • MCP프로토콜 2025-06-18, 2025-03-26, 2024-11-05. 메서드 initialize, ping, tools/list, tools/call와 JSON-RPC 배치. 도구만 있고 resources와 prompts는 없습니다.
  • 저장소샌드박스 앱은 사람이 Branchlane에서 연 저장소만 열 수 있습니다. 아니면 도구가 그렇다고 오류로 알려 줍니다.
