저장소에 워크트리가 둘 이상이고 Pro를 쓰면, Branchlane은 <git common dir>/branchlane/worktrees.json을 적어도 1분마다 새로 씁니다. MCP를 못 쓰는 에이전트는 워크트리마다 git status를 도는 대신 이 파일을 읽으면 됩니다. 워크트리가 하나만 남으면 지워집니다.

{
  "version": 1,
  "about": "…",
  "generatedAt": "2026-11-23T02:09:00Z",
  "target": "refs/heads/main",
  "worktrees": [
    { "path": "…", "branch": "lane/retry-sync-a7f4", "head": "…",
      "access": "readable", "uncommittedFiles": ["Sources/Sync/SyncEngine.swift"], "lastChange": "…" }
  ],
  "collisions": [
    { "between": ["…", "…"], "conflicts": false, "sameFiles": ["Sources/Sync/SyncEngine.swift"],
      "conflictLines": { "Sources/Sync/SyncEngine.swift": [["40-60", "41"]] } }
  ]
}

읽어 보기

파일은 Git 공통 폴더 안에 있으니 어느 워크트리에서든 같은 경로로 찾습니다.

f="$(git rev-parse --git-common-dir)/branchlane/worktrees.json"

# 워크트리마다 미커밋 파일 수
jq -r '.worktrees[] | "\(.branch)\t\(.uncommittedFiles | length)"' "$f"

# 실제로 충돌할 쌍만
jq '.collisions[] | select(.conflicts)' "$f"
