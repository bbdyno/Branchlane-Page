    private/by-design

    There is no Branchlane server to send your code to.

    Repository data leaves your Mac only when you ask, and only to the place you chose.

    Your Mac Local Git, with tokens and API keys in macOS Keychain
    Your Git remoteWhen you clone, fetch, pull, or push
    GitHub or GitLabOnly if you add your own token
    The AI provider you set upOnly when you run an AI action. Local and on-device models stay on your machine.
    Branchlane serverDoes not exist. No account, cloud sync, or analytics backend either.
