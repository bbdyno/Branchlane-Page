Questions, answered

Before you start.

Everything important about the free plan, trial, billing, privacy, and the App Sandbox.

When does the free trial start?

Downloading Branchlane does not start the trial. It starts only after an eligible new subscriber selects a Pro plan and confirms the offer in the app.

Is Free time-limited?

No. Everyday Git stays free with no time limit: staging, committing, branching, merging, plain rebase, remote sync, undo, history, and blame, with up to 3 repository tabs.

Do Monthly and Yearly differ?

No. Both unlock the same Pro features. The only differences are billing frequency and price.

How do I cancel or restore?

Manage or cancel through your App Store account settings. Existing purchases can be restored inside Branchlane.

Who decides trial eligibility?

The App Store determines eligibility for introductory offers. Branchlane shows the available offer before you confirm.

Does a subscription upload my code?

No. StoreKit handles subscription state, and there is no Branchlane server. Repository data leaves your Mac only when you ask: to a Git remote you chose, to GitHub or GitLab with your own token, or to the AI provider you configured.

Why do some scripts and hooks need a Terminal command?

macOS quarantines files written by App Store apps. Scripts and Git hooks that arrive through a clone, pull, or checkout in Branchlane need one Terminal command before they can run: xattr -dr com.apple.quarantine <repo>. Branchlane shows the command when this blocks a Git operation. Files Branchlane writes later need it again. Hooks already on disk run normally.
